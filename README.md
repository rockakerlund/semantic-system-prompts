# Semantic Systems Prompts

This repository is not a collection of random prompt examples.  
It’s a structured way of showing **how I use prompts as tools for thinking, learning, and creating value.**

## Why this exists
Most "prompt example" repos are superficial.  
I want to demonstrate a deeper approach:  
- How the **structure of a question** changes the quality of the answer  
- How prompts can guide AI toward **clarity, not filler**  
- How AI can be used as a **teaching partner and project tool**  

## Contents
- `clarity-prompts.md` → Prompts that bring sharp and precise answers  
- `value-prompts.md` → Prompts that direct AI toward real-world value  
- `learning-prompts.md` → Using AI as a tutor (math, programming, systems thinking)  
- `project-prompts.md` → How I document and guide projects with AI agents  

## Example
**Prompt:**  
Explain the associative property in multiplication using two-digit numbers, and give a practical example.  

**AI’s answer:**  
(12 × 5) × 2 = 12 × (5 × 2) → both equal 120.  
Changing the brackets doesn’t change the result.
