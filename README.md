# Semantic Systems Prompts

This repository is not a collection of random prompt examples.  
It’s a structured way of showing how I use prompts as tools for thinking, learning, and creating value.

---

## Why this exists
Most "prompt example" repos are superficial.  
Here I want to demonstrate a deeper approach:

- How the structure of a question changes the quality of the answer  
- How prompts can guide AI toward clarity, not filler  
- How AI can be used as a teaching partner and project tool
